## Scratchpad

The site is gamified forum. This instance will focus on Kep1er. It has:

- Forum (cafe) for discussion.
  - Section containing a board for each of the 9 members.
  - Another section for general Kep1er and K-pop discussion as well as off-topic discussion.
  - The forum contains post which is called a **topic**. Topic can be replied. Each reply can also be replied as a comment.
  - Topic has view counts.
  - Topic and reply have like counts.
- The entire site will be gamified
  - Level & EXP, coins, badges, shop, collections, etc.
- Customizable widgets for personalization:
  - Schedule calendar
  - Chart tracker
  - Live event countdown
  - Member birthday
- Other noises content:
  - Hot posts
  - Today's user birthday
  - Polls
  - Most popular cafe
  - Latest cafe post
  - Top user today/week/month/alltime
  - New users
- Board as a one-way announcement from member to fans.
  - Forum is for discussion while board is like an announcement system from official or members.
- Profile system
  - Profile is used in the website.
  - Guestbook to leave public message for the user.
  - Typical profile like bio, profile picture, bias, mood/status.
  - Has mailbox for direct message.
- Quest system
  - Daily quest, account quest: e.g., read 5 posts today, assign your bias, comment in your bias forum, etc.
  - Mission gives EXP, coins, or badges
- Attendance system
  - Login streak
- Badges system
  - Badges are collectible obtained through quests or shop.
  - Some badges are exclusive e.g., "Login during anniversary".
- Activity
  - Tracks user activity and show it in their profile.
- Dynamic theme system
  - Theme is switcahble to different comeback era
  - e.g., Debut (light theme, dark purple accent)
  - KILLA (dark theme, dark red accent)
- Level system
  - Gain EXP from attendance, quests, or posting.
  - Level up gives coins
  - Use coins to buy gift, title, badges, and other collectibles.
- Ranking system
  - Richest user, highest level user, etc.

Homepage should look like a lobby, aggregating various content such as forum board, birthday, etc.
